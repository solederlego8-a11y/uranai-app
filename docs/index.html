このアプリの特徴

  • 結論がひとつ。11種の結果を重み付き平均で統合し、100点満点の総合評価と大吉〜凶のランクを提示します。
  • 日替わり。「今日の日付」を計算に組み込むため、同じ人でも日付が変われば結果が変わります。
  • 完全に決定論的。乱数は一切使用していません。同じ入力・同じ日付なら必ず同じ結果になります。
  • 個別結果も確認可能。11種それぞれの鑑定は、結論の下のアコーディオンから読めます。

高島暦（高島易断の暦）で自分の運勢や方位のページを引くには、まず生年月日から「本命星」を知る必要があります。本命星は生まれ年で決まり、1月1日から立春の前日までに生まれた人は前の年の星になります。この記事では、1935年〜2027年生まれの本命星を一覧にした早見表と、表を使わずに西暦から計算する手順をまとめます。早見表は九星気学の一般的な算出法で当サイトが計算したもので、特定の暦本の掲載内容を転載したものではありません。

30秒で判断

  • 本命星は生まれ年で決まる。下の早見表で自分の生まれ年を探すだけでよい
  • 1月1日〜立春の前日（2月3日ごろ）生まれは、前の年の星を見る。立春は年によって2月3日〜5日のあいだで動く
  • 計算する場合は「西暦の各桁を1桁になるまで足し、11から引く」。答えが10以上なら9を引く

生年月日から本命星を調べるには、何を見ればよい？

見るのは「生まれた年」と「誕生日が立春より前か後か」の2点です。本命星とは、九星気学で生まれ年に割り当てられる星のことで、一白水星から九紫火星までの9種類があります。星は毎年ひとつずつ数字が小さくなる順（九紫→八白→七赤…→一白→九紫）で巡り、9年で一周します。

立春より前に生まれた人は、なぜ前の年の星になる？

九星気学では、1年の始まりを1月1日ではなく立春に置くためです。立春とは二十四節気のひとつで、国立天文台が毎年発表する暦要項に日付が載っています。2月4日になる年が多いものの、年によって前後することがあります。

そのため、2月3日〜5日に生まれた人は、生まれた年の立春が何日だったかで星が変わる場合があります。該当する人は、国立天文台の暦要項で生まれ年の立春の日付を確認してください。当サイトの総合鑑定は2月4日を境にした簡易計算のため、2月3日〜5日生まれの人は結果が実際の立春と1年ずれる可能性があります。

誕生日見る年例
1月1日〜2月2日前の年1990年1月20日生まれ → 1989年の二黒土星
2月3日〜5日生まれ年の立春の日付を確認して判断立春当日以降なら生まれ年、前日までなら前の年
2月6日〜12月31日生まれた年1990年6月1日生まれ → 1990年の一白水星

早見表がないとき、西暦から計算するには？

西暦の各桁を足して1桁にし、11から引くと本命星の数字になります。手順は次のとおりです。

  • 1. 立春より前の生まれなら、西暦から1を引く
  • 2. 西暦の4つの数字を足す。2桁になったら、もう一度各桁を足して1桁にする
  • 3. 11からその数字を引く。答えが10以上なら9を引く

例：1990年6月生まれ → 1+9+9+0＝19 → 1+9＝10 → 1+0＝1 → 11−1＝10 → 10−9＝1 で、一白水星。1985年生まれ → 1+9+8+5＝23 → 2+3＝5 → 11−5＝6 で、六白金星。どちらも上の早見表と一致します。

本命星が分かったら、暦のどこを読めばよい？

九星別の運勢と、方位のページです。令和九年版の高島易断本暦は、楽天ブックスに掲載されている目次によると、九星の説明、令和9年の各月の方位盤、吉日を選ぶ方法などを収録しています。本命星が分かっていれば、自分の星のページと方位盤をすぐに引けます。シリーズ4種の違いは高島易断の本暦・開運本暦・運勢本暦の違いで整理しています。

月命星や今日の方位まであわせて見たい場合は、今日の総合鑑定に生年月日を入力すると、九星気学の結果欄に本命星と月命星が表示されます（無料）。九星気学の考え方は九星気学の解説にまとめています。

よくある質問

高島暦の早見表はどこに載っていますか

暦本の種類や年版によって掲載位置や形式が異なるため、この記事では特定のページを案内していません。生まれ年から本命星を知るだけであれば、この記事の早見表か、西暦からの計算で調べられます。

早生まれ（1月〜3月生まれ）は前の年の星になりますか

前の年になるのは、立春の前日までに生まれた人だけです。学年の早生まれ（1月1日〜4月1日）とは区切りが違い、立春以降の2月・3月生まれは生まれた年の星を見ます。

2026年生まれの本命星は何ですか

2026年の立春以降〜2027年の立春前日に生まれた人は一白水星です。2026年1月1日〜立春前日に生まれた人は、2025年の二黒土星になります。

本命星と月命星は何が違いますか

本命星は生まれ年、月命星は生まれ月から決まる星です。月命星は本命星と生まれ月の組み合わせで決まるため、先に本命星を調べます。

本命星で運勢は決まりますか

決まりません。九星は伝統的な占いの区分で、科学的な根拠に基づくものではありません。予定を考えるときの目安のひとつとして使う程度で十分です。

チベット占星術

チベット占星術とは｜五大元素・メワ・パルカで読む運命

チベット占星術は、インドの占星術と中国の陰陽五行思想がチベット仏教の文化のなかで融合して生まれた体系です。十二支・五大元素・九宮数（メワ）・八卦（パルカ）という4つの要素を組み合わせて運命を読み解きます。

十二支と五大元素の組み合わせ

チベット暦にも十二支があり、ネズミ・ウシ・トラ・ウサギ・龍・ヘビ・ウマ・ヒツジ・サル・トリ・イヌ・ブタと、日本の十二支とほぼ同じ動物が並びます。

これに木・火・土・金・水の五大元素が組み合わさります。元素は2年ごとに切り替わるため、十二支と元素の組み合わせは60年で一巡します。「木のトラ年」「火のウサギ年」といった呼び方をするのが特徴です。

木は伸びる力で成長と拡大を、火は燃える力で情熱と変化を、土は支える力で安定と蓄積を、金は断つ力で決断と純化を、水は巡る力で知性と柔軟を司ります。

メワ（九宮数）とは

メワは1から9までの数で、それぞれに色が結びついています。1・6・8は白、2は黒、3は青、4は緑、5は黄、7・9は赤です。中国の洛書に由来する九星と同じ発想で、九星気学の本命星と同じ計算式で求めます。

白のメワは清らかさと再出発、黒のメワは障害を乗り越えることで増す力、青のメワは活力と行動力、緑のメワは調和と人縁、黄のメワは中心に立つ影響力、赤のメワは情熱と名誉を象徴します。

パルカ（八卦）は性別で計算式が変わる

パルカは、易の八卦にあたる要素です。リ（離＝火）・クン（坤＝地）・ダ（兌＝沢）・ケン（乾＝天）・カン（坎＝水）・ゴン（艮＝山）・シン（震＝雷）・ソン（巽＝風）の8つがあります。

チベット占星術の特徴的な点として、パルカの計算式が性別によって異なります。男性は（100 − 生年の下2桁）÷ 3 を 8 で割った余り、女性は（生年の下2桁 + 4）÷ 3 を 8 で割った余りで求めます。これは陰陽の巡り方が男女で逆になるという東洋思想の考え方を反映したものです。

当サイトでは、性別に「回答しない」を選択された場合、男性の式で計算しています。この点は算出方法の明示という観点から、鑑定結果の詳細文にも記載しています。

当サイトでの計算方法

十二支は1924年を子年として12年周期で求め、五大元素は十二支のインデックスを2で割って5で循環させています。メワは九星気学と同じ立春補正付きの計算式、パルカは上記の性別別の式です。

その日の運勢は、今日の日柱の十二支とあなたの十二支の相性（三合・支合・冲などを評価）と、あなたの元素と今日の天干の五行の関係を組み合わせて算出しています。ラッキーカラーは五大元素、ラッキーアイテムと方位はパルカから決定しています。

成り立ちと広まり

チベット占星術は、大きく分けて中国由来の「ナクツィ（黒の占星術）」と、インド由来の「カルツィ（白の占星術）」の二つの系統があります。ナクツィは十二支・五大元素・メワ（九宮）・パルカ（八卦）を用いる体系で、当サイトの鑑定はこの系統にもとづいています。カルツィはインドの『カーラチャクラ・タントラ』を源流とし、惑星の運行を計算する天文学的な体系です。

チベットでは占星術は医学と結びついて発展し、ラサのメンツィカン（医学暦法研究所）で暦の作成と占星術の教育が行われてきました。毎年発行されるチベット暦には、その年の吉凶や日々の注意が記されています。

チベット占星術の五大元素は「木・火・土・鉄・水」で、中国の五行（木・火・土・金・水）の「金」が「鉄」になっています。この元素と十二支の組み合わせで60年の周期を作る点は、中国の干支と同じ構造です。

鑑定結果の読み方（例）

当サイトの鑑定では、生まれ年の十二支と元素、メワ、パルカと、今日の運勢が表示されます。生まれ年が「木の虎」なら、虎の行動力と木の成長する性質を持つ、「鉄の犬」なら、犬の忠実さと鉄の堅さ・鋭さを持つ、と読みます。元素は性質の「質感」を、十二支は行動の「型」を表すと考えると理解しやすいでしょう。

メワは1〜9の数で、白・黒・青・緑・黄・赤の色と結びつき、生まれ年から求めます。九星気学の九星と同じく3×3の魔方陣の構造を持ち、その年に自分のメワがどの位置に巡るかで運気の流れを読みます。パルカは八卦（リ・コン・ダ・キン・ケン・カム・ギン・ズィン）で、男性と女性で計算の方向が逆になる点がチベット占星術の特徴です。

チベット占星術では、運気を「ソク（生命力）・ル（身体）・ワンタン（力・影響力）・ルンタ（運気・風の馬）」の四つの側面で読みます。今日の運勢は、これらのうち今日の元素と自分の元素の相性で変化する側面を中心に判定しています。

他の占術との違いと組み合わせ

九星気学のメワ（九星）とチベットのメワは同じ魔方陣の構造を持ちますが、色と数の対応、年の区切り（チベット暦の新年は2〜3月のロサル）が異なります。四柱推命の干支とチベットの十二支・元素も構造は似ていますが、元素の名称と、年の始まりが異なります。

チベット占星術に特有なのは、パルカが性別によって変わる点と、運気を四つの側面（ソク・ル・ワンタン・ルンタ）で分けて読む点です。この四側面の考え方は、他の東洋占術にはありません。

当サイトの総合鑑定では、チベット占星術を「今日の生命力・身体・影響力・運気のどれが動く日か」の指標として、他の占術の吉凶と並べて表示しています。

鑑定結果を日常でどう使うか

チベット占星術の四つの側面（ソク・ル・ワンタン・ルンタ）は、体調や運気を分けて考える枠組みとして使えます。「今日はルが強い日」と出たら身体を使う予定を、「ワンタンが強い日」なら交渉や発表を、「ルンタが強い日」なら新しい試みを、というように、当サイトの今日の運勢を予定の種類に対応させます。

生まれ年の元素と十二支の組み合わせは、自分の「質感」を知る材料です。例えば火の元素は活動的で明るいが燃え尽きやすい、水の元素は柔軟で深いが流されやすい、というように、元素の性質を長所と注意点の両面で読むと、日常の自己理解に役立ちます。

チベットでは暦を見て日取りを決める習慣があり、旅行や引っ越し、契約の日を吉日に合わせる考え方があります。当サイトでは詳細な日取りの判定は扱っていませんが、今日の運勢を「大きな予定を入れる日かどうか」の参考にする使い方ができます。

総合鑑定の中でのチベット占星術の位置づけ

当サイトの総合鑑定では、チベット占星術を含む11種の占術を同じ入力から同時に計算し、一覧で表示しています。チベット占星術の結果として表示されるのは主に「十二支・元素・メワ・パルカと四つの側面」で、これを他の占術の結果と並べて読むことで、その日の傾向を複数の視点から確認できます。

複数の占術が同じ方向（例えば「今日は控えめに」「今日は進める」）を示した項目は、その傾向を意識して過ごす材料にしやすく、逆に占術ごとに結果が分かれた日は、判断をご自身の状況に委ねる日と考えると、鑑定を無理なく日常に取り入れられます。

各占術には成り立ちも計算方法も異なる体系があり、当サイトはそれらの優劣を判定するものではありません。チベット占星術の結果に関心を持たれた場合は、この記事で紹介した用語と考え方を手がかりに、専門の書籍や鑑定で深めていただければと思います。

よくある質問

チベット暦の新年はいつですか

チベット暦の新年（ロサル）は、太陰太陽暦にもとづき、毎年2月から3月の間で変わります。生まれ年の十二支と元素は、この新年を境に決まるため、1〜3月生まれの人は前年の干支になることがあります。当サイトの年の区切りは「当サイトでの計算方法」の項をご覧ください。

パルカが男女で違うのはなぜですか

チベット占星術では、パルカ（八卦）を生まれ年から数える際に、男性は一定の方向、女性はその逆の方向に数える規則があります。これは陰陽の考え方にもとづくもので、同じ生まれ年でも性別によって異なるパルカになります。

ルンタとは何ですか

ルンタ（風の馬）は、チベットで運気や幸運を象徴する概念で、祈祷旗（タルチョ）に描かれる馬の図柄でも知られます。占星術では、四つの側面のうち「運気」を表し、ルンタが強い日は物事が進みやすい日とされます。

チベット医学と関係がありますか

チベット医学では、体質を風・胆汁・粘液の三つの要素で見ますが、占星術の五大元素とも関連づけて、治療や薬の処方の時期を暦で選ぶ伝統があります。当サイトの鑑定は医学的な判断を含みません。

十二支の動物は中国と同じですか

ほぼ同じ12の動物（ネズミ・牛・虎・兎・龍・蛇・馬・羊・猿・鳥・犬・猪）ですが、チベット暦では新年がロサル（2〜3月）で区切られるため、1〜3月生まれの人は中国の干支と異なることがあります。

メワと九星気学の九星は同じですか

どちらも3×3の魔方陣にもとづく9つの数で、構造は共通です。ただし、色の対応と年の区切りが異なり、同じ生まれ年でも数が一致しないことがあります。

チベット占星術と中国の四柱推命は同じですか

ナクツィは中国の干支・五行の影響を受けていますが、元素の名称（鉄と金）、パルカの性別による計算、四つの側面（ソク・ル・ワンタン・ルンタ）など独自の要素があります。

チベット暦はどこで見られますか

メンツィカンなどが発行する年間の暦があり、チベット関連の書店やWebサイトで入手できます。当サイトの鑑定は暦の詳細な日取り判定は含みません。

チベット占星術を学べる場所はありますか

日本語の解説書は少なく、英語の文献やチベット関連の団体の講座で学ぶ人が多いようです。当サイトの鑑定は入口として、基本の用語と考え方を確認する目的でお使いください。

チベット仏教と占星術は関係がありますか

チベットでは占星術が仏教寺院や医学と結びついて伝承されてきました。暦の作成や儀式の日取りに占星術が使われる一方、占い自体は仏教の教義そのものではありません。

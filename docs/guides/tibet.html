チベット占星術

チベット占星術とは｜五大元素・メワ・パルカで読む運命

チベット占星術は、インドの占星術と中国の陰陽五行思想がチベット仏教の文化のなかで融合して生まれた体系です。十二支・五大元素・九宮数（メワ）・八卦（パルカ）という4つの要素を組み合わせて運命を読み解きます。

十二支と五大元素の組み合わせ

チベット暦にも十二支があり、ネズミ・ウシ・トラ・ウサギ・龍・ヘビ・ウマ・ヒツジ・サル・トリ・イヌ・ブタと、日本の十二支とほぼ同じ動物が並びます。

これに木・火・土・金・水の五大元素が組み合わさります。元素は2年ごとに切り替わるため、十二支と元素の組み合わせは60年で一巡します。「木のトラ年」「火のウサギ年」といった呼び方をするのが特徴です。

木は伸びる力で成長と拡大を、火は燃える力で情熱と変化を、土は支える力で安定と蓄積を、金は断つ力で決断と純化を、水は巡る力で知性と柔軟を司ります。

メワ（九宮数）とは

メワは1から9までの数で、それぞれに色が結びついています。1・6・8は白、2は黒、3は青、4は緑、5は黄、7・9は赤です。中国の洛書に由来する九星と同じ発想で、九星気学の本命星と同じ計算式で求めます。

白のメワは清らかさと再出発、黒のメワは障害を乗り越えることで増す力、青のメワは活力と行動力、緑のメワは調和と人縁、黄のメワは中心に立つ影響力、赤のメワは情熱と名誉を象徴します。

パルカ（八卦）は性別で計算式が変わる

パルカは、易の八卦にあたる要素です。リ（離＝火）・クン（坤＝地）・ダ（兌＝沢）・ケン（乾＝天）・カン（坎＝水）・ゴン（艮＝山）・シン（震＝雷）・ソン（巽＝風）の8つがあります。

チベット占星術の特徴的な点として、パルカの計算式が性別によって異なります。男性は（100 − 生年の下2桁）÷ 3 を 8 で割った余り、女性は（生年の下2桁 + 4）÷ 3 を 8 で割った余りで求めます。これは陰陽の巡り方が男女で逆になるという東洋思想の考え方を反映したものです。

当サイトでは、性別に「回答しない」を選択された場合、男性の式で計算しています。この点は算出方法の明示という観点から、鑑定結果の詳細文にも記載しています。

当サイトでの計算方法

十二支は1924年を子年として12年周期で求め、五大元素は十二支のインデックスを2で割って5で循環させています。メワは九星気学と同じ立春補正付きの計算式、パルカは上記の性別別の式です。

その日の運勢は、今日の日柱の十二支とあなたの十二支の相性（三合・支合・冲などを評価）と、あなたの元素と今日の天干の五行の関係を組み合わせて算出しています。ラッキーカラーは五大元素、ラッキーアイテムと方位はパルカから決定しています。
